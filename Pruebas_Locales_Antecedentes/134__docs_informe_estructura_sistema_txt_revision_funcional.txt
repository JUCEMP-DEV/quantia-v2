0008 ============================================================

0010 - Frontend: Vue 3 + Vite + Pinia + Vue Router.

0012

0016 - La raiz ya incluye carpeta `backups/` para respaldos de proyecto.

0107 ============================================================
0108 5) FLUJO END-TO-END VIGENTE
0109 ============================================================
0110 1. Usuario inicia sesion o se registra.
0111 2. Usuario captura etapas: registro -> clasificacion -> modelo espacial -> preliminares -> modulos.
0112 3. Frontend ejecuta simulaciones intermedias con `/api/motor/...`.
0113 4. En revision, frontend envia snapshot auditado a `/api/resultados/inferir`.
0114 5. Backend responde con:
0115    - `resultadoFinal`
0116    - `desglose.technicalConcepts`
0117    - `desglose.officialSummary`
0118    - `estadoResultado`
0119    - `metadata`
0120 6. Frontend confirma revision y guarda snapshot en `/api/cotizaciones`.
0121 7. Frontend muestra salida imprimible con resultado persistido.
